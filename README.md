## 🚨 `> ls -la ~/operations/`

> **Mission briefing:** My projects run the full purple-team loop — attack to learn how adversaries move, defend by turning that knowledge into detections, and automate with AI so the loop runs faster every cycle. Everything is hands-on: real logs, real alerts, real attack scenarios.

| Operation | Side | Description |
|-----------|:----:|-------------|
| 🖥️ **SOC / Threat Detection Labs** | 🔵 | Hands-on SIEM work — ingesting and analyzing logs, writing custom detection rules, and triaging alerts end-to-end in simulated SOC environments that mirror real enterprise networks |
| 🚩 **CTF & Purple Team Exercises** | 🟣 | University-led CTFs and security challenges — attacking targets, then switching sides to trace footprints, build detections, and mitigate the same techniques |
| 🤖 **AI Security Automation** | 🤖 | Python tooling that automates the repetitive side of security — log parsing, bulk IP reputation checks, and reconnaissance scripts that turn hours of manual triage into seconds |
